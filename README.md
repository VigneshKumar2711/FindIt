# FindIt – Campus Lost and Found Management System

FindIt is a web application designed to help students report, search, and manage lost and found items within a campus.

## Features

- User Login and Registration
- Report Lost Items
- Report Found Items
- Student Dashboard
- Admin Dashboard
- Search and Filter Reports
- Admin Report Verification
- Activity Tracking
- Responsive User Interface

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- React Hook Form
- Zod
- Framer Motion
- Lucide React

## Getting Started

Clone the repository and install dependencies:

npm install

Start the development server:

npm run dev

## Production Build

npm run build
